name=dzetsaka : Classification tool
qgisMinimumVersion=3.0
qgisMaximumVersion=4.99
description=Raster classification in QGIS with 11 machine learning algorithms, Optuna hyperparameter search, SHAP explanations, class imbalance handling, and HTML reports.
version=5.1.0
author=Nicolas Karasiak
email=karasiak.nicolas@gmail.com

about=
      dzetsaka is a QGIS plugin that classifies remote sensing images and other multiband rasters.

      - 11 classifiers: GMM, RF, SVM, KNN, XGBoost, CatBoost, ET, GBC, LR, NB, MLP
      - Optuna hyperparameter search
      - SHAP explanations and confidence maps
      - Class imbalance handling (SMOTE, class weights, nested CV)
      - Guided wizard and compact dashboard
      - Reusable recipes and HTML reports

      For documentation and updates: https://github.com/nkarasiak/dzetsaka/

tracker=https://github.com/nkarasiak/dzetsaka/issues
